## 2. Key Modules Implemented

### 2.1 CAD Engine Adapter (`com.eurowindow.cadviewer.engine`)
- **`CadEngineContracts.kt`**: Defined domain-level abstractions independent of MLightCAD internal details:
  - `CadPoint(x, y, z)`
  - `CadLayer(id, name, isVisible, colorHex)`
  - `DrawingInfo(fileName, fileExtension, title, layerCount, bounds)`
  - `MeasurementResult(type, value, unit, points, timestamp)`
  - `CadEngineException` hierarchy (FileNotFound, UnsupportedFormat, DwgFeatureDisabled, ParseFailure, RendererCrash).
- **`MlightCadAdapter.kt`**:
  - Implements `CadEngine` interface.
  - Enforces policy: `ENABLE_COMMERCIAL_DWG_PARSER = false`. Any attempt to load DWG without commercial license fails with `DwgFeatureDisabledException` immediately before executing JS.
  - Zero GPL fallback.
  - Communicates asynchronously with WebView via JavaScript bridge (`window.EurowindowBridge`).

### 2.2 SAF Pipeline (`com.eurowindow.cadviewer.saf`)
- **`SafManager.kt`**:
  - Launches Android Storage Access Framework via `Intent.ACTION_OPEN_DOCUMENT`.
  - Configured with MIME types: `application/dxf`, `image/vnd.dxf`, `model/vnd.dwg`, `image/vnd.dwg`.
  - Takes persistable URI read permissions (`takePersistableUriPermission(uri, FLAG_GRANT_READ_URI_PERMISSION)`).
  - Streams file bytes into memory with progressive read buffer (8KB chunks) and cancellation support.
  - **Data Integrity:** Never requests `WRITE` or `CREATE_DOCUMENT` permissions. Source files remain 100% untouched.

### 2.3 Room Metadata Database (`com.eurowindow.cadviewer.data`)
- **`CadDatabase.kt`**: Local SQLite database storing:
  - `drawing_metadata`: `uriString` (Primary Key), `displayName`, `extension`, `fileSize`, `lastOpenedTimestamp`, `isFavorite`, `thumbnailPath`.
  - `measurement_sidecars`: `documentUriString`, `measurementType`, `measurementValue`, `unit`, `pointsJson`, `createdAtTimestamp`.
- **Zero Content Leak:** Drawing vector entities, geometry, or confidential customer CAD contents are **never** copied into the database.

### 2.4 WebView AssetLoader Runtime (`com.eurowindow.cadviewer.webview`)
- **`CadWebViewComponents.kt`**:
  - Uses `androidx.webkit.WebViewAssetLoader` with domain `cad.eurowindow.local`.
  - Virtual origin: `https://cad.eurowindow.local/assets/web-runtime/index.html`.
  - Bypasses `file:///` sandbox restrictions, enabling Web Workers (`mtext-renderer-worker.js`) and WebAssembly.
  - Crash recovery: Implements `onRenderProcessGone()` to intercept OOM crashes gracefully.
  - Navigation restriction: Blocks any request not starting with `https://cad.eurowindow.local/`.

### 2.5 Jetpack Compose Navigation & Screens (`com.eurowindow.cadviewer.ui`)
- Clean, CAD-focused user interface inspired by DWG FastView:
  1. **Recent (Gần đây):** Displays sorted history of opened drawings with badges, file size, timestamps, and delete action.
  2. **Favorites (Yêu thích):** Filtered view of pinned engineering drawings.
  3. **Drawings (Bản vẽ):** SAF document picker button.
  4. **Settings (Cài đặt):** Units configuration (mm), CAD engine status, and licensing disclaimer.
  5. **Viewer (Màn hình CAD):** Embedded WebView, back navigation, zoom-to-fit trigger, and progress indicator.
