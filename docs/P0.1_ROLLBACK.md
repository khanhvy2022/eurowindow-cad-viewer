## 2. Trigger Conditions for P0.1 Rollback
An immediate rollback to `checkpoint-p0.0` must be executed if:
1. Android project scaffolding or Gradle configuration introduces unresolvable circular dependencies.
2. Any GPL-3.0 component (`@mlightcad/libredwg-converter`, `libredwg-web`, or GPL wasm) contaminates the production release dependency graph.
3. Original DWG or DXF drawing files undergo modification, renaming, or corruption during SAF read operations (`SHA256_before != SHA256_after`).
4. Any files belonging to the user's external Eurowindow AI Studio or global system directories are modified.
