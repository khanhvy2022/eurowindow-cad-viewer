# Eurowindow CAD Viewer (Android)

**Application ID:** `com.eurowindow.cadviewer`  
**Milestone:** P0 — Offline CAD Viewer + Measurement  
**Primary Engine:** MLightCAD  
**Platform:** Android (Kotlin + Jetpack Compose)  

---

## Overview
Eurowindow CAD Viewer is a high-performance, strictly offline Android CAD viewer designed for viewing and measuring architectural and window/door drawings (DWG/DXF) without requiring external cloud connectivity.

## P0 Supported Features
- Open DXF and DWG drawings offline.
- Fast pan, zoom, pinch-to-zoom, and fit-to-drawing.
- Full layer visibility toggling.
- High-precision distance, angle, and area measurements with unit switching (mm, cm, m, inch, feet).
- Clean DWG FastView-style navigation: Recent, Favorites, Drawings, Settings.
- 100% read-only original file integrity (measurements stored as independent sidecar metadata).
- Dual-language UI (Vietnamese & English).
